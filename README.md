# Atelier_Docker_Bases

Bac à sable : Codespace
1° - Créez un compte Github
2° - Créez un nouveau Repository
3° - Mettre un fichier README dans ce Repository
4° -  Lancer Codespace (Onglet [CODE] -> Codespace)
5° - Allez dans le terminal de Codespace
6° - Montez votre Docker :
docker run -d -p 80:80 quay.io/ocp-edge-qe/httpd
7° - Mettre en visibilité public votre URL (Clique droit sur l'URL disponible dans les [PORT])
Travail demandé : Coller l'URL de votre site Web (It works!) dans la discussion général de ce Discord
